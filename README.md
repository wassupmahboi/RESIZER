# RESIZER
A program that Resizes your image files (.jpg, .jpeg, .png, .gif) to half its original size.

## [DOWNLOAD THE LATEST VERSION (v0.1)](https://github.com/wassupmahboi/RESIZER/releases)

## How to use?
- Download [main.py](https://github.com/wassupmahboi/RESIZER/blob/main/main.py) or the [.exe file](https://github.com/wassupmahboi/RESIZER/releases).
- Put the program in the same folder which contains the images you want to resize.
- **NOTE: THE ABOVE MENTIONED FOLDER CAN HAVE FILES OTHER THAN IMAGES AND/OR SUBFOLDERS WITH IMAGE FILES. THE PROGRAM WILL JUST SKIP THE OTHER FILES.**
- If you are using the python file, make sure you have the following libraries downloaded:
  1. os
  2. re
  3. pathlib
  4. pillow **[This is usually the one which is not pre installed with Python]**
- If you are downloading RESIZER.exe, just click and enjoy :)
- The resized images will pop up one by one. Download them and save in a seperate folder.
